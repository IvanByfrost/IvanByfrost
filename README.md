## 🚀 Proyectos

### 🛂 Cristóbal
Sistema de autorización de ingreso de contratistas para la Universidad del Rosario. Lo propuse, lo diseñé y lo construí solo.
- Cargue masivo asíncrono, sin duplicados (la cédula es la llave) y con historial de cambios.
- Cálculo automático de vigencias y de autorizaciones vencidas.
- Lectura de planillas en PDF con IA (Gemini): **precisión del 80 % al 98 %** tras ajustar los prompts por operador.
- Migré ~30.000 registros históricos de Excel a MySQL.
- **Stack:** Java 21 · Spring Boot · Spring Security + JWT · MySQL · React · Ant Design · Python

### 🏍️ INSFORTEC
Plataforma de e-learning y pagos para una escuela de mantenimiento de motos. El cliente pidió saber quién pagó; propuse además saber quién debe, y hoy tiene control de cartera.
- Pagos por cuotas, mora por fecha de vencimiento y carga masiva de aprendices desde Excel.
- Backend con ~50 endpoints, CI/CD con GitHub Actions y despliegue en DigitalOcean con ambientes de pruebas y producción.
- Aprendí Node.js y Angular sobre la marcha, y entregué en plazo.
- **Stack:** Node.js · Express · TypeScript · Angular · PostgreSQL · Docker · Nginx

### 📽️ SamUR Remote
Gestión remota de equipos Windows y proyectores AV desde un panel web: ping, Wake-on-LAN, encendido y apagado, y estado de video.
- Detecta el protocolo de cada proyector: PJLink, Epson ESC/VP.net, Crestron y Extron.
- **Stack:** Java · Spring Boot · React · Vite · Tailwind

### 🌉 [Byfrost](https://github.com/IvanByfrost/byfrost-showcase)
Plataforma SaaS educativa **multi-tenant** con asistencia de IA e inclusión escolar (PIAR). Organizada en módulos con nombres de mitología nórdica: autenticación, gobernanza multi-tenant, núcleo académico, notificaciones, suscripciones, inclusión y voz con IA.
- **Stack:** Java · Spring Boot · React · Python (FastAPI) · PostgreSQL · Redis

### ✈️ [TouristChain](https://github.com/IvanByfrost/touristchain)
Plataforma de turismo con buscador de destinos, itinerarios dinámicos, mapas y pagos. Enfocada en la transparencia y la confianza del viajero.
- **Stack:** React · TypeScript · Tailwind CSS
